ANTES DE PUBLICAR NO GITHUB PAGES

1. Preserve o config.js que já funciona no seu GitHub Pages.
2. Extraia este pacote.
3. Substitua o config.js deste pacote pelo seu config.js atual, com a URL e a Publishable Key do Supabase.
4. Envie os arquivos para a raiz do repositório.
5. Não é necessário executar nenhum SQL para esta atualização visual.
6. Após a publicação, abra o site e pressione Ctrl + F5.
