ANTES DE PUBLICAR NO GITHUB PAGES

1. Preserve o config.js que já está funcionando no seu GitHub Pages.
2. Extraia este pacote.
3. Substitua o config.js deste pacote pelo seu config.js atual.
4. Envie os arquivos para a raiz do repositório.
5. Aguarde o deploy do GitHub Pages.
6. Abra o site e pressione Ctrl + F5 para limpar o cache.

Não é necessário executar SQL no Supabase para esta atualização visual.
