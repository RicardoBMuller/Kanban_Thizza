# Kanban Quest — FCC Visual Original Restaurado

Esta versão retorna ao visual escuro original do projeto e mantém as melhorias de contraste e legibilidade das fontes.

## Publicação

1. Preserve o `config.js` atualmente funcional no GitHub Pages.
2. Extraia o ZIP.
3. Substitua o `config.js` do pacote pelo seu arquivo atual.
4. Envie os arquivos para a raiz do repositório.
5. Após o deploy, pressione `Ctrl + F5`.

## Supabase

Nenhuma alteração de banco é necessária para esta atualização. Não execute novamente o SQL de recriação.
